## Projetos

### [SafeWear](https://safewear-sp.vercel.app)

PWA de segurança urbana. Mostra o nível de atenção de cada área a partir de dados públicos de criminalidade, sugere rotas mais seguras e tem SOS com compartilhamento de localização.

- **Stack:** Next.js, TypeScript, MapLibre, Turso (libSQL), Drizzle, Web Push
- **Engenharia:** monorepo com três pacotes (app, núcleo e pipeline de dados), dados atualizados por GitHub Actions, testes com Vitest e Playwright
- **Código:** privado (projeto em grupo)

### [Mascot Desk](https://mascot-desk.vercel.app)

App de produtividade com um mascote 3D que reage ao que você faz: foco, tarefas, notas, agenda e estudo com flashcards e revisão espaçada. Abre em modo visitante, sem login.

- **Stack:** Next.js, TypeScript, Three.js, Tailwind CSS, Zustand
- **Engenharia:** CI em todo push, testes unitários, de propriedade, de acessibilidade e ponta a ponta
- **Código:** privado

### [Trancoso Fishing](https://trancoso-fishing.vercel.app)

Site institucional de uma operação de pesca esportiva, em HTML, CSS e JavaScript puros. [Código](https://github.com/jaoguedes/trancoso-fishing).
